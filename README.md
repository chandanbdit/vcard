# Digital Visiting Card 🌐

A modern, lightweight, and responsive digital visiting card designed for fast, touchless professional networking. Built with clean HTML5, CSS3, and vanilla JavaScript, it provides instant access to contact details, social profiles, and direct communication channels.

👉 **Live Demo:** [https://chandan-mondal.github.io/vCard/](https://chandan-mondal.github.io/vCard/)

---

## ✨ Features

* **Instant Contact Saving:** Direct one-tap vCard (`.vcf`) download to instantly save details to iOS and Android address books.
* **Direct Actions:** Quick-launch buttons for calling, emailing, WhatsApp messaging, and website redirection.
* **Social & Professional Hub:** Integrated links for LinkedIn, GitHub, X (Twitter), and Facebook.
* **Mobile-First Responsive Design:** Optimized UI/UX ensuring flawless rendering and lightning-fast load times across all devices.
* **Zero Dependencies:** Built without heavy frameworks for maximum performance and security.

---

## 🛠️ Built With

* **HTML5** – Structured, semantic markup
* **CSS3** – Modern, responsive styling
* **JavaScript** – Interactive elements and vCard handling
* **GitHub Pages** – Free, secure, and fast hosting
